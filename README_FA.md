# راهنمای قالب صفحه اشتراک سنایی

قالب دو زبانه و واکنش‌گرا برای پنل‌های Sanaei، 3x-ui و X-UI.

[English Guide](README.md) | [پشتیبانی خصوصی تلگرام](https://t.me/proxystore11) | [کانال تلگرام](https://t.me/proxystoreadmin)

## قبل از نصب

- پنل باید روی یک سرور لینوکس اجرا شود.
- سرور برای دریافت فایل قالب به اینترنت دسترسی داشته باشد.
- برای نصب به دسترسی مدیر یا `root` نیاز دارید.

## نصب سریع

این دستور را در یک خط روی سرور لینوکس اجرا کنید:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/miladfaryad11/sanaei-sub-template/main/install.sh)
```

اگر از ویندوز استفاده می‌کنید، همین دستور را داخل WSL یا ترمینال SSH متصل به سرور لینوکس اجرا کنید.

نصب‌کننده آخرین فایل `sub.html` را دانلود می‌کند، پوشه قالب را می‌سازد، از نسخه قبلی backup می‌گیرد و قالب را در مسیر زیر قرار می‌دهد:

```text
/etc/x-ui/sub/sub.html
```

## تنظیم پنل سنایی

1. وارد تنظیمات پنل شوید.
2. به بخش `Subscription -> Information` بروید.
3. گزینه `Subscription page template folder` را پیدا کنید.
4. مسیر زیر را وارد کنید:

```text
/etc/x-ui/sub
```

5. تنظیمات را ذخیره کنید و لینک اشتراک را دوباره باز کنید.

## به‌روزرسانی قالب

هر زمان نسخه جدید منتشر شد، همان دستور نصب را دوباره اجرا کنید. قبل از جایگزینی، نصب‌کننده از فایل قبلی backup زمان‌دار می‌سازد.
