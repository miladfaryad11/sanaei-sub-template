# راهنمای نصب قالب صفحه اشتراک سنایی

## نصب خودکار

این دستور را در یک خط اجرا کنید:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/miladfaryad11/sanaei-sub-template/main/install.sh)
```

فایل قالب در مسیر `/etc/x-ui/sub/sub.html` نصب می‌شود.

در ویندوز، همین دستور یک‌خطی را داخل WSL یا ترمینال SSH متصل به سرور لینوکس اجرا کنید.

## تنظیم پنل سنایی

در پنل به مسیر `تنظیمات پنل -> Subscription -> اطلاعات -> پوشه قالب صفحه اشتراک` بروید.

مقدار `/etc/x-ui/sub` را وارد کنید، ذخیره بزنید و لینک اشتراک را دوباره باز کنید.
