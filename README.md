# Sanaei Subscription Template Installation

## Install

Run this command in one line:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/miladfaryad11/sanaei-sub-template/main/install.sh)
```

The template is installed at `/etc/x-ui/sub/sub.html`.

On Windows, run the same one-line command in WSL or through an SSH terminal connected to the Linux server.

## Panel Settings

Open `Panel Settings -> Subscription -> Information -> Subscription page template folder`.

Set the folder to `/etc/x-ui/sub`, save the settings, and reopen a subscription link.
